# Script de démonstration — 2 minutes 30

1. Présenter le problème : le conseiller doit rassembler les informations avant de répondre à une coopérative.
2. Saisir une coopérative de démonstration, la culture manioc, la zone Estuaire et un scénario de pluie.
3. Lancer l'analyse et montrer le niveau de risque, les raisons et la provenance des données.
4. Souligner que l'analyse est une heuristique de démonstration, pas une prédiction agronomique validée.
5. Cliquer sur Approuver ou Rejeter et montrer le changement de statut.
6. Expliquer que le serveur MCP expose les outils métier. Montrer un appel MCP dans le terminal si le temps le permet.
7. Conclure : l'agent prépare, un humain décide.

Ne pas prétendre que la météo est en direct ni que le modèle a été entraîné sur des données gabonaises.
